# LACIS — Laboratório de Cultura, Informação e Sociedade

## Sobre o projeto

O projeto consiste no desenvolvimento de uma plataforma web para apresentar e centralizar informações sobre o **Laboratório de Cultura, Informação e Sociedade (LACIS)**.

O site reúne informações institucionais do laboratório, incluindo agenda de atividades, apresentação, textos, pesquisas e uma seção dedicada aos dirigentes municipais de cultura.

Na seção de dirigentes, representantes dos municípios de todo o Brasil podem enviar suas informações, que são organizadas e disponibilizadas na plataforma, contribuindo para a construção de uma base de informações sobre a gestão cultural nos municípios brasileiros.

## Tecnologias utilizadas

- **Backend:** PHP com Laravel
- **Frontend:** React com Vite
- **Banco de dados:** MySQL
- **Arquitetura:** API REST

## Desenvolvimento

O projeto é uma iniciativa de Iniciação Científica, iniciada em 2026, e desenvolvido colaborativamente por uma equipe formada por estudantes de diferentes institutos e unidades da Universidade de São Paulo (USP).

A aplicação é hospedada na Escola de Comunicações e Artes (ECA-USP).

## Objetivo

Centralizar e facilitar o acesso às informações do LACIS, além de disponibilizar um espaço para reunir dados dos dirigentes municipais de cultura de todo o Brasil.
